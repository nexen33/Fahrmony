Fahrmony Privacy Policy & Safety Statement Fahrmony 隐私政策与安全承诺 Fahrmony Datenschutzerklärung Fahrmony プライバシーポリシー

Fahrmony adheres to the absolute principle of local computation, ephemeral memory handling, and zero data telemetry. We operate no cloud databases, require no user accounts, and process all in-car bridging locally within your device.

Fahrmony 恪守“绝对本地运行、用完即焚、零隐私索取”的设计准则。我们不设任何自建服务器，无账号登录，不跟踪设备标识，所有消息与媒体投屏均在您的手机内存沙盒内即时完成。

Fahrmony basiert auf dem fundamentalen Prinzip der vollständigen lokalen Datenverarbeitung und des Null-Datentransfers. Die Anwendung betreibt keine eigenen Cloud-Datenbanken, erfordert keine Registrierung und verarbeitet Medien- und Benachrichtigungsdaten rein flüchtig.

Fahrmonyは「完全ローカル処理・揮発性メモリ即時破棄・個人データ不取得」の原則を厳格に遵守します。独自のクラウドサーバーやユーザー登録は一切不要であり、端末内部で安全に動作します。

01

Overview & Core Philosophy 概述与核心准则 Übersicht & Leitprinzipien 概要および基本原則

No Accounts & No Tracking: Fahrmony requires no user registration, assigns no user identifiers (UUID/IMEI/MAC), and embeds zero commercial advertising or crash tracking SDKs (no Firebase, no telemetry beacons, no Sentry, no Bugly).

Bridge Middleware: Fahrmony operates purely as a lightweight automotive middleware projecting media states to Android Auto. It does not store, host, or pirate copyrighted media files.

无账号体系与无身份识别：本应用不需要用户注册账号，不分配任何跨应用跟踪的用户唯一标识符（UUID/IMEI/MAC地址），不接入任何第三方商业统计分析插件（无 Firebase、无 Bugly、无友盟等）。

非独立音乐播放器：Fahrmony 仅充当轻量级车载中间件，负责将手机已安装音频软件的媒体会话转接给车机大屏，不托管、不下载、不缓存任何音频版权文件。

Keine Konten & kein Tracking: Die Anwendung erfordert keine Benutzerregistrierung, vergibt keine Gerätekennungen und bindet keine kommerziellen Analyse- oder Werbe-SDKs ein.

Reine Middleware: Fahrmony dient ausschließlich der Übertragung von Medieninformationen an Android Auto und speichert oder hostet keine urheberrechtlich geschützten Audiodateien.

アカウント不要・トラッキング皆無：本アプリはユーザー登録や識別子（IMEI/MAC/UUID等）の付与を行わず、商用広告やクラッシュ解析SDK（Firebase、Bugly等）を一切搭載しません。

車載連携ミドルウェア：Fahrmonyは端末内の音楽再生状態をAndroid Auto画面へ安全に投影するミドルウェアであり、音声ファイルを保存・配信・改ざんすることはありません。

Regulatory Compliance (GDPR, CCPA & Android Auto) 国际法规遵从性 (GDPR / CCPA) Einhaltung internationaler Datenschutzgesetze 国際法規への準拠 (GDPR / 個人情報保護法)

Legal Bases (GDPR Article 6) 合法处理依据 (GDPR 第6条) Rechtsgrundlagen (Art. 6 DSGVO) 適法処理の根拠 (GDPR第6条)
  • Art. 6(1)(a) Consent: Processing of notification content relies entirely on the user explicitly granting Android Notification Access, which can be revoked anytime in system settings. Art. 6(1)(a) 用户明示同意：通知监听权由用户在系统“通知使用权”中主动授权，用户可随时在手机系统设置中一键撤销。 Art. 6 Abs. 1 lit. a DSGVO: Ausdrückliche Einwilligung über die Android-Berechtigungseinstellungen (jederzeit widerrufbar). 第6条第1項(a) 利用者の明示的同意：端末の「通知アクセス権」にて随時有効化および撤回が可能です。
  • Art. 6(1)(b) Functional Performance: Processing of active media session states is strictly necessary to project playback metadata and controls to Android Auto. Art. 6(1)(b) 履行用户指令：媒体会话状态同步是执行用户主动发起的“车机大屏播放控制”所不可或缺的纯本地技术交互。 Art. 6 Abs. 1 lit. b DSGVO: Erforderlich zur Erbringung der vom Nutzer veranlassten Fahrzeugsteuerung. 第6条第1項(b) 契約または指示の履行：車載画面へのメディア情報連携という利用者自身の要求に基づく機能提供に限定されます。

Data Minimization (Art. 5(1)(c), (e) GDPR): All notification payloads and media session tokens are processed ephemerally in volatile memory (RAM) with a retention period of zero. No personal messages are committed to non-volatile disk storage.

数据最小化与存储期限限制 (Article 5 GDPR)：所有传入的通知载荷与媒体会话全过程仅在手机运行内存（Volatile RAM）中即时处理，保留期限为零。绝不将任何个人通讯内容持久化至本地存储。

Datenminimierung (Art. 5 DSGVO): Alle Benachrichtigungsinhalte werden ausschließlich flüchtig im Arbeitsspeicher (RAM) verarbeitet. Die Speicherdauer beträgt 0 Sekunden.

データの最小化と保存制限 (GDPR第5条)：受信した通知データおよび再生セッションは、端末の揮発性メモリ（RAM）上でのみ一時的に処理され、保存期間はゼロです。

Outbound Network Requests Disclosure 外部网络请求详细披露 Offenlegung ausgehender Netzwerkverbindungen 外部ネットワーク通信の開示

1. On-Demand Public Lyrics Retrieval: Triggered only when the active media player does not report embedded lyrics. Transmits strictly the track title and artist name. Contains NO device identifiers (IMEI, MAC, Android ID, IP tracking), NO user tokens, and NO account credentials.

2. GitHub Releases Version Check: Automated once daily in background or manually triggered. Performs a standard read-only GET request to https://api.github.com/repos/nexen33/Fahrmony/releases/latest to check for updates. No personal data or telemetry is collected.

1. 在线歌词单向检索：仅在当前播放曲目未包含歌词时，单向从公开在线渠道检索纯文本歌词（仅传输歌名与歌手，不包含任何设备信息、用户标识或 Cookie）。

2. GitHub Releases 版本检测：按需向官方公开的 GitHub API 发起只读版本号比对，仅用于提醒用户安全更新，绝不上传设备硬件码或行为特征。

1. Bedarfsweiser Online-Songtextabruf: Überträgt ausschließlich Titel und Interpret, sofern keine Songtexte lokal vorliegen. Enthält keinerlei Geräte-IDs, IP-Tracking oder Cookies.

2. GitHub-Versionsprüfung: Regelmäßige schreibgeschützte Abfrage der offiziellen GitHub Releases API zur Prüfung auf Sicherheitsaktualisierungen.

1. オンライン歌詞の単方向取得：再生中の楽曲に歌詞が含まれていない場合のみ、公開されたオンライン歌詞ソースから曲名とアーティスト名のみで検索を行います（端末固有情報、IP追跡、Cookieは含まれません）。

2. GitHub Releases バージョン確認：安全な利用のため、公式GitHub APIへ定期的に読み取り専用リクエストを行い、最新リリースを確認します。

Third-Party Libraries & Sub-Processors 第三方库与境外传输 Keine Drittanbieter-Tracker und Drittlandübermittlung 第三者提供および国外移転の不存在

Zero Trackers: Fahrmony contains zero advertising SDKs, zero telemetry beacons, and zero crash tracking frameworks (no Firebase, no Sentry, no Bugly).

Zero International Transfers (Art. 44+ GDPR): Because all personal data is processed solely on the local device, no cross-border transfer of personal data occurs.

零追踪器：无广告 SDK、无统计打点、无崩溃收集探针（无 Firebase、无 Bugly、无友盟）。

无境外传输：所有数据均在个人手机本地运算，不存在个人数据出境或第三方共享。

Keine Werbe- oder Analyse-SDKs: Keine Einbindung von Firebase, Bugly, Google Analytics oder vergleichbaren Tracking-Diensten.

Keine Drittlandübermittlung (Art. 44 ff. DSGVO): Da alle Verarbeitungen ausschließlich lokal auf Ihrem Endgerät stattfinden, erfolgt keine Übermittlung personenbezogener Daten in Drittländer.

トラッカーの不使用：広告SDK、マーケティング分析ツール、クラッシュ報告ツール（Firebase、Bugly等）は一切導入していません。

国外移転の不存在 (GDPR第44条以降)：すべてのデータ処理はユーザー端末内で完結するため、個人データの第三国移転は発生しません。

Data Retention, Local Storage & User Rights 数据存储、删除机制与用户权利 Speicherung, Löschung und Betroffenenrechte データの保管・消去および利用者の権利

Retention: Transient notification data is destroyed upon vehicle disconnect. Local preferences (theme, preferred player) are stored in local SharedPreferences.

Right to Erasure (Art. 17 GDPR): Users can wipe all local preferences instantly via Android Settings -> Apps -> Fahrmony -> Storage -> Clear Data, or by uninstalling the Application.

Right to Lodge a Complaint (Art. 77 GDPR): Users have the right to lodge a complaint with a competent data protection supervisory authority in their EU member state of residence.

CCPA / CPRA Statement: We do not sell, rent, or share personal information with third parties.

存储机制：通知数据用完即焚；本地设置（主题、默认播放器）存储在 Android 本地 SharedPreferences。

彻底删除权 (Art. 17 GDPR)：用户可随时通过系统设置清除应用存储或卸载，即可瞬间完全销毁所有本地配置文件。

申诉权 (Art. 77 GDPR)：若认为数据处理不合规，用户有权向所在地区的监管机构提出申诉。

CCPA 承诺：绝不出售、出租或共享任何个人数据。

Löschung (Art. 17 DSGVO): Nutzer können alle lokalen Einstellungen jederzeit über die Android-Systemeinstellungen („Speicherinhalt löschen“) oder durch Deinstallation restlos entfernen.

Beschwerderecht (Art. 77 DSGVO): Sie haben das Recht, sich bei einer Datenschutz-Aufsichtsbehörde Ihres Wohnsitzes zu beschweren, wenn Sie der Ansicht sind, dass die Verarbeitung gegen die DSGVO verstößt.

CCPA-Zusicherung: Wir verkaufen, vermieten oder teilen keine persönlichen Daten mit Dritten.

消去権 (GDPR第17条 / 忘れられる権利)：端末の「設定」->「アプリ」->「Fahrmony」->「ストレージを消去」またはアプリのアンインストールにより、ローカル設定をいつでも完全に消去できます。

監督機関への不服申立て (GDPR第77条)：EU居住者は、所轄のデータ保護監督機関に異議を申し立てる権利を有します。

情報販売・共有の禁止 (CCPA)：個人情報の第三者への販売・共有は一切行いません。
