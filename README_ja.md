# Fahrmony

![Platform](https://img.shields.io/badge/Platform-Android%20Auto%20%7C%20Android-green)
![Capacitor](https://img.shields.io/badge/Capacitor-v8-blue)
![React](https://img.shields.io/badge/React-v19-cyan)
![Kotlin](https://img.shields.io/badge/Kotlin-Native-purple)
![License](https://img.shields.io/badge/License-CC%20BY--NC%204.0-red)

> Android Auto 向けに設計されたローカル相互運用ブリッジ。海外でのドライブ中、使い慣れた中国語圏の音楽ストリーミングやメッセージ通知を車載画面で自然に表示し、一部操作できるようにします。

## Fahrmony とは

**Fahrmony** という名称は、ドイツ語で「運転」を意味する **Fahren** と、英語の **Harmony**（調和・シンクロ）を組み合わせて名付けられました。

海外在住で Android Auto 搭載車を運転する多くのドライバーにとって、日常的に親しんでいる地域の音楽・ポッドキャストやメッセージアプリが車載エコシステムに直接対応していないことは、長年の不便な課題でした。スマートフォンで音楽を再生していても車内では単純な Bluetooth 接続に頼らざるを得ず、ステアリングスイッチや車載ディスプレイからの選曲や進捗調整が行えませんでした。また、走行中に WeChat や Feishu などのメッセージを受信した際、スマートフォン画面に視線を落として確認する危険な操作も生じがちでした。

**Fahrmony は、この断絶を安全に解消するために開発されました。** root 権限やシステムの改変を一切必要とせず、Android 標準の公式インターフェースのみを利用して軽量な車載ミドルウェアとして機能します。スマートフォンのバックグラウンド再生を Android Auto の全画面および分割画面（Coolwalk を含む）に正確に投影し、メッセージ通知を安全運転基準に準拠した音声読み上げとして車内に届けることで、海外でのドライブをより快適で安心なものにします。

### Fahrmony が行わないこと

- **単体の音楽プレーヤーではありません**：独自の音声デコーダーやストリーミング配信機能は備えていません。
- **元のアプリを置き換えるものではありません**：アカウント管理、会員権限、プレイリストの管理や実際の音声生成は、すべて端末内の公式アプリが担当します。
- **メディアの保存や中継配信は行いません**：音声データのダウンロードや外部サーバー経由の通信は一切行いません。
- **Root 権限は不要です**：通常の Android アプリのセキュリティ境界内で安全に動作します。
- **非公開プロトコルの解析は行いません**：商用アプリの非公開 API 解析やパケット改ざんは一切行いません。

## 動作の仕組み

Fahrmony は Android の公式標準インターフェースのみを用いて双方向ブリッジを構築しています：

1. **音声メディアの連携**：端末内で再生中の音源を検出し、その状態を車載メディアサービスに双方向マッピング。車載画面やステアリングスイッチから直接操作できます。
2. **メッセージ通知の連携**：受信した通知を解析し、車載安全基準に適合した形式に変換。車載音声アシスタントによる安全な読み上げを実行します。
3. **プロセス分離設計**：車載バックグラウンド処理は独立した `:car` システムプロセス内で常駐稼働し、スマートフォンのフロントエンド画面と物理的に分離されています。

## 主な機能

- **車載標準メディア操作**：ダッシュボード上で再生、一時停止、前の曲／次の曲へのスキップ、シークバー操作が可能。
- **セッション検出と自動調停**：再生中の音源セッションを自動検出し、アプリ切り替え時にも再生状態を安定してロック。表示の乱れを防ぎます。
- **コールドスタートと自動起動**：車載画面で再生を要求した際、停止中の対象アプリを自動的に喚起して再生を開始。初期化待ちのリトライ機能も搭載。
- **適応型背景生成**：独自のカラー生成エンジンにより、暗いアルバム画像やオフライン再生時に車載ボタンが黒く潰れて見えなくなる問題を防止。
- **再生キューとリピート連携**：元のアプリが提供するプレイリストを車載側に表示。標準のリピート機能や各種モード切り替えに対応。
- **安全運転メッセージ通知**：グループチャットの連続通知を賢くフィルタリング。「既読」操作や音声読み上げに対応。
- **切断時の音漏れ防止**：ケーブル抜去時に瞬時に再生を一時停止。選曲時の連打による画面のチラつきも防止。
- **極簡スマートフォン管理画面**：スマートフォン上で動作する設定画面。ダーク／ライトモードおよび多言語切り替えに対応。

## 互換性マトリクス

> **基本方針**：互換性は技術的な標準インターフェースに基づいており、特定のアプリブランドに依存しません。標準のメディアセッションまたはシステム通知を発行するアプリであれば動作します。

| 機能 | サポート状況 | 実装方式と動作概要 | 制限事項と前提条件 |
| :--- | :---: | :--- | :--- |
| **再生・一時停止** | **完全対応** | 標準メディア制御コマンドを発行、誤連打防止ロックを適用 | 元アプリが標準メディアインテントを正しく処理すること |
| **曲送り・曲戻し** | **完全対応** | 標準スキップコマンドを発行、状態遷移ロックを適用 | 一部のラジオやポッドキャストでは曲戻しが未実装の場合あり |
| **シークバー操作** | **対応** | 再生位置を直接伝達し、プログレスバーを同期 | ライブ配信やシーク非対応の音声では操作不可 |
| **曲情報・アーティスト表示** | **完全対応** | 曲名、アーティスト名、アルバム名を取得して表示 | 元アプリの曲情報配信が遅延する場合、一時的にアプリ名を表示 |
| **カバー背景** | **適応型生成** | 車載ボタンの視認性を確保する高コントラスト背景を生成 | 画面のちらつきや遅延を防ぐため、直接の画像転送を抑制 |
| **再生キュー** | **透過対応** | 元アプリがキュー情報を公開している場合、車載リストを表示 | リストを公開していないアプリでは一覧ボタンが非表示になります |
| **リピートモード** | **適応型対応** | 標準設定を優先確認し、未対応時は拡張アクションを中継 | 元アプリ側の実装仕様に依存します |
| **シャッフル再生** | **限定対応** | 元アプリが専用のアクションを提供している場合のみ動作 | 多くのストリーミングアプリは標準規格外のため非対応 |
| **コールドスタート起動** | **完全対応** | 停止中のアプリを自動起動し、準備完了後に再生指示 | 端末側のバックグラウンド自動起動許可が必要 |
| **メッセージ通知表示** | **完全対応** | チャット構造を解析し、車載標準の通知カードを生成 | 端末の「通知へのアクセス」許可が必要 |
| **音声読み上げ** | **システム制御** | 車載音声アシスタントが安全基準に従って自動朗読 | 読み上げの言語や音声は端末の音声設定に依存 |
| **直接返信** | **非対応** | 「既読」ボタンによる消去に対応。**元アプリへの代理返信は非対応** | メッセージアプリが外部送信用の公開 API を提供していないため |

## 動作要件

- **スマートフォン OS**：Android 10.0 以降（Android Auto がシステムに標準搭載されており、接続するだけですぐに使用可能。Android 9.0 の場合は Google Play からの手動ダウンロードにより下位互換対応）。
- **車載環境**：有線またはワイヤレス接続に対応した **Android Auto** 搭載車載機、または公式 PC 向けエミュレーター（DHU）。
- **アプリ環境**：標準的な音楽再生アプリやメッセージアプリが端末にインストールされていること。

## インストール手順

1. **APK のダウンロード**：本リポジトリの [Releases ページ](https://github.com/nexen33/Fahrmony/releases) から最新の `Fahrmony_v1.0.0.apk` をダウンロードします。
2. **権限の付与**：
   - アプリを起動し、案内に従って **「通知へのアクセス」** を有効化します；
   - 長距離ドライブ時のバックグラウンド強制終了を防ぐため、**「電池の最適化の除外（無制限）」** に設定します；
   - Android 13 以降をご利用の場合は **「通知の送信」** 権限を許可してください。
3. **Android Auto 開発者向け設定**：
   - 端末の設定 -> `Android Auto` を検索して開きます；
   - 最下部のバージョン番号を10回連続タップして開発者モードを有効化します；
   - 右上のメニュー -> **開発者向け設定** -> **「提供元不明のアプリ」** にチェックを入れます。
4. **車両との接続**：USB ケーブルまたはワイヤレスで接続すると、車載ディスプレイ上に **Fahrmony** のアイコンが表示されます。

## 必要な権限

システム設定ファイルにて宣言されている全権限と実際の用途は以下の通りです：

| 権限名 | 対象コンポーネント | 実際の用途と技術的説明 |
| :--- | :--- | :--- |
| **インターネット接続** | 画面コンテナの基礎環境 | 画面表示コンテナの標準仕様です。**アプリ内部には外部通信コード、サーバー接続、解析ツールは一切存在せず、データは一切外部へ送信されません。** |
| **通知へのアクセス** | メディアおよび通知の連携 | 最も重要な権限です。再生中のメディアセッションを検出したり、メッセージ通知を車載用に変換するために使用します。処理はメモリ内でのみ完结します。 |
| **フォアグラウンドサービス実行** | バックグラウンドの安定化 | 画面消灯時や別のアプリ使用中にも車載リンクを途切れさせないために使用します。 |
| **メディア再生フォアグラウンドサービス** | 車載メディア再生 | Android システムに対してメディアサービスを宣言し、高い優先度で車載操作に応答します。 |
| **データ同期フォアグラウンドサービス** | プロセス間同期 | スマートフォンの設定画面と車載バックグラウンドサービス間で安全に状態を同期します。 |
| **通知の送信** | 車載メッセージ通知 | Android 13 以降で車載用の通知カードを送信し、ダッシュボード上で表示・読み上げさせるために必須です。 |
| **電池の最適化の除外** | 長時間ドライブ時の保護 | 長時間走行中にスマートフォンの省電力機能によってバックグラウンド常駐が停止されるのを防ぎます。 |

## トラブルシューティング

### 1. 車載画面に Fahrmony のアイコンが表示されない
- **原因**：Android Auto の開発者設定で「提供元不明のアプリ」が有効になっていません。
- **対処**：設定 -> Android Auto -> バージョン番号10回タップ -> 開発者向け設定 ->「提供元不明のアプリ」にチェックを入れ、ケーブルを再接続してください。

### 2. 「再生待機中」と表示され、音源リストが出てこない
- **原因**：端末起動直後など、対象の音楽アプリが一度もメディアセッションを生成していません。
- **対処**：スマートフォン側で音楽アプリを一度開いて何か再生するか、車載リストの音源名をタップして起動を試みてください。

### 3. 曲名が表示されない、または「再生中」のままになる
- **原因**：一部のアプリで曲情報の配信が再生開始から数秒遅れることがあります。
- **対処**：Fahrmony は通知欄から曲名を自動補完するため、少しお待ちいただくと自動的に正しい表示に更新されます。

### 4. 再生・停止はできるが「次の曲」「前の曲」が反応しない
- **原因**：再生中の音声（ライブ配信やラジオなど）自体がスキップ機能を備えていません。
- **対処**：元アプリの実装仕様によるものであり、異常ではありません。

### 5. 車載画面からタップしてもアプリが起動しない
- **原因**：OS がバックグラウンドでの自動起動を制限しています。
- **対処**：端末の設定 -> アプリ -> Fahrmony および対象の音楽アプリで「自動起動の許可」や「バックグラウンド実行」を許可してください。

### 6. リピートやシャッフルボタンが反応しない
- **原因**：対象のアプリが標準のリピート操作に対応していません。
- **対処**：誤動作を防ぐため、車載側の表示は標準状態に保たれます。

### 7. メッセージを受信しても車載画面に通知や読み上げが出ない
- **原因**：通知へのアクセス権限が無効になっているか、設定でグループチャットの除外が有効になっています。
- **対処**：Fahrmony の設定画面を開き、すべての権限が許可されていることを確認してください。

### 8. 走行中に突然接続が途切れる
- **原因**：スマートフォンの省電力機能がバックグラウンドサービスを強制終了しています。
- **対処**：バッテリー設定から、Fahrmony およびご利用の音楽アプリのバッテリー使用量を「無制限」に設定してください。

## プライバシー

1. **完全ローカル完結**：通知の取得、テキスト解析、メディア状態の同期は**すべて端末の一時メモリ（RAM）上でのみ処理**され、ストレージへの保存は行いません。
2. **外部サーバーなし**：遠隔サーバーの設置や接続は一切行わず、ネットワーク通信量はゼロです。
3. **解析ツールなし**：広告配信、行動追跡、クラッシュ解析用の商用モジュールは一切組み込まれていません。
4. **いつでも無効化可能**：付与した権限はスマートフォンのシステム設定からいつでも解除できます。

## よくある質問

#### 車載画面からメッセージに直接返信できないのはなぜですか？
安全運転の確保と技術的境界の両立のためです。運転中に画面上で文字を入力することは非常に危険です。また、主要なメッセージアプリは外部返信用インターフェースを公開していません。Fahrmony は安全な読み上げに徹し、安全性を最優先しています。

#### なぜアルバム画像ではなくグラデーションカラーが表示されるのですか？
外部アプリの暗いアルバム画像やオフライン再生により、Android Auto の自動配色が車載ボタンを真っ黒にしてしまい、見えなくなる不具合を防ぐためです。また、画像の直接転送による画面の引っかかりを防ぎ、常にスムーズな選曲と高い視認性を両立しています。

#### 音声は車とスマートフォンのどちらから出力されますか？
車載機に接続中は自動的に車両側のスピーカーから出力されます。接続ケーブルを抜いた際は、音漏れ防止機能が瞬時に全再生を一時停止させ、スマートフォンのスピーカーから突然大音量で鳴るのを防ぎます。

#### 乗車するたびにスマートフォン側でアプリを開く必要がありますか？
いいえ。バックグラウンド自動起動の許可が設定されていれば、車載画面から曲を再生するだけで、自動的にバックグラウンドで目的のアプリが起動して再生が始まります。
